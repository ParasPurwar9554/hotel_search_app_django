# 🏨 Hotel Search App

A full-stack hotel search application built using **Django, Vue.js, and Bootstrap**.

The application allows users to browse available hotels and dynamically filter and sort them based on their requirements.

## ✨ Features

- 🏨 Browse hotels
- 🔍 Search hotel information
- 🏷️ Filter hotels by amenities
- 💰 Filter hotels by maximum price
- ↕️ Sort hotels by price
- 🖼️ Hotel banner and image management
- 📱 Responsive Bootstrap UI
- 🔗 Django API for hotel data
- 🛠️ Django Admin for managing hotels and amenities

## 🛠️ Tech Stack

- **Backend:** Django
- **Frontend:** Vue.js 3
- **UI:** Bootstrap 5
- **Database:** SQLite / PostgreSQL
- **Language:** Python
- **API:** Django JSON API
- **Media:** Django Media Files

## 📌 Project Purpose

This project demonstrates how Django can be combined with Vue.js to build a dynamic hotel search platform with API-driven filtering, sorting, and hotel management.
